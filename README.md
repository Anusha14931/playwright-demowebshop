# Playwright Automation Framework - Demo Web Shop

An automated end-to-end (E2E) testing framework built with **Playwright** and **JavaScript**, utilizing the **Page Object Model (POM)** design pattern.

## 🚀 Features
* **Page Object Model (POM):** Keeps locators and test actions cleanly separated.
* **Data-Driven Testing:** Pulls user registration data dynamically from an external JSON file.
* **Playwright Test Runner:** Fast, reliable browser automation.

## 📁 Project Structure
* `Pages/registerpage.js`: Page object class containing element locators and registration methods.
* `testdata/register.json`: External JSON test data file.
* `tests/register.spec.js`: Main test script executing the registration workflow.
